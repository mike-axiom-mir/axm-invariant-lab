## What the pinned evidence shows

For `held-disconnect-recover`, the donor regression serializes a checkpoint containing accepted engine receipts, verifies it locally, then sends only the serialized checkpoint plus fixture identity to a fresh Node process. The fresh receipt equals the local receipt, and checkpoint digest, engine receipt IDs, and engine state digest agree.

The adversarial control changes an inner engine-receipt packet payload, deletes/recomputes the outer checkpoint digest, and submits the resealed checkpoint to the fresh verifier. It still returns `HOLD / CHECKPOINT_REPLAY` with process exit 2. Therefore an outer digest alone is not treated as sufficient continuity evidence when replay identity disagrees.

The verifier's authority fields remain false for automatic resume, transport mutation, canonical-state mutation, merge, and CANON. Verification is evidence, not authority.

Hosted donor run `34586268082` completed successfully on the exact donor head `0cef53c3900c48a4d7cece62bcbfd6fa34f40fab`; both Node 20 and Node 22 jobs passed the focused fresh-process regressions and the complete Stateborn suite.

## Invariant Lab implementation

`adapters/state_research_stateborn_checkpoint.py` checks a mechanical projection only. Missing required evidence returns HOLD. Source/blob drift, fresh/local disagreement, loss of the resealed-inner-tamper counterexample, unsafe authority escalation, or process-admission drift returns FAIL.

The deterministic retained receipt is generated by `tools/run_state_research_stateborn_checkpoint_refinement.py` and checked in CI.

## Truth boundary

This does **not** execute Stateborn inside Invariant Lab, prove complete transport-session resume, prove durable persistence or crash atomicity, authenticate the checkpoint producer, establish hostile-peer security, prove real networking, or create merge/CANON authority. State Research explicitly states that the checkpoint does not contain the complete transport tick/queue/retry/event-ledger/live-session state.

The evidence supports INV-09 only on the exact pinned checkpoint-v2 state-language reconstruction boundary. General model fidelity remains capped at seed rung 5; this is not a new rung promotion.
